## Findings

Spark has zero failed extraction tasks and one partial observations task. Its
attribute accuracy is .8787, highest here. NVIDIA BF16 has the highest vision
item F1 (.8185). Beam variants have nearly equal item F1; NVFP4 uses four GPUs
rather than eight but has more partial tasks (10 versus 2). NVIDIA NVFP4 remains
a useful one-GPU throughput candidate.

Fastino has 22 failed and 10 partial tasks, including five failed summaries and
six failed timeline event tasks. LiLiCorr loses an entire article to roster
failure. Their low recall is partly pipeline failure, not merely missed facts.

Remaining failures include unresolved source spans, contradictory temporal
relations, rejected erasure during repairs, and invalid figure descriptions that
block panel attribution. Keep strict evidence and chronology validation. Staged
extraction is operational, but this run alone cannot isolate its causal benefit
because generation and pipeline workloads changed.

RedHat draft acceptance is 1.75%, versus 27.67–62.42% for the other speculative
arms. Acceptance alone is not a speedup measurement. Run the already-supported
redhat-fp8-no-spec control with identical sources and target settings before
changing its default recipe. RedHat also exhausted output length during human
article measurement-series extraction. Fastino produced conflicting measurement
objects. These are the only two actual EHR generation failures; LiLiCorr EHR was
blocked by its missing roster.

All 1,823 recorded calls retained text reasoning. Training exports must still
filter for source-supported facts, valid task results, and appropriate dataset
splits; reasoning presence is not correctness.
