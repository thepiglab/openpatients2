# Synthetic examples only

These notes and expected extractions were newly authored for software testing. They are not real patient data, not model-generated clinical evaluation results, and not evidence of model accuracy.

`synthetic-input.jsonl` is the source fixture; `synthetic-patient.jsonl` is the merged mock-HTTP output; `synthetic-cohort.jsonl` shows tumor-linked cohort membership with exact evidence spans. Run `uv run op2 demo --output runs/demo` to reproduce the full process. `terms.local-demo.csv` contains illustrative local IDs, not licensed clinical terminology.

The reasoning fixtures are also synthetic: `synthetic-extraction-with-reasoning.jsonl` demonstrates returned mock reasoning stored beside the extraction, and `synthetic-reasoning-disagreements.jsonl` shows the review queue. `../reports/reasoning-demo.md` and `.json` contain a labeled six-case/three-mode/two-repeat mock study. These percentages exercise report logic; they are NOT K2/Motif scores. Full reproducible state is generated by `uv run op2 reasoning-demo --output runs/reasoning-demo`.

`synthetic-source-enrichment.jsonl` and `synthetic-article-figures.jsonl` are a seven-row mocked discovery example. Their identifiers, captions, MD5 strings and image URLs are deliberately fictional test fixtures, not a set of usable medical images. No images were downloaded. Reproduce with `uv run op2 sources-demo --output runs/sources-demo`.
